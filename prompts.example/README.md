# 自定义提示词(模板)

skill 中需要判断的三步——检查范围、标注研究问题、写脉络报告——在动手前都会先读项目里的
`<lineage 输出目录>/prompts/`。在那里写下你的要求，就能改变 Claude 的做法，不用改 skill 本身
(改 skill 会在 `git pull` 更新时冲突或被覆盖)。

用法：把需要的模板复制过去，删掉不需要的段落，再按自己的领域改写。

```bash
mkdir -p <lineage目录>/prompts
cp ~/.claude/skills/research-lineage/prompts.example/narrative.md <lineage目录>/prompts/
```

| 文件 | 何时读取 | 用途 |
|---|---|---|
| `scope.md` | 分析之前 | 领域定义：锚点论文、收录条件、不收清单。论文集偏离它时，Claude 会先指出来，而不是照单分析 |
| `questions.md` | 标注研究问题时(步骤 3b) | 问题树的偏好：固定的根问题、命名方式、粒度 |
| `narrative.md` | 写脉络报告时(步骤 4) | 报告的结构、侧重点、篇幅、语气 |
| `extra.md` | 每一步 | 其他通用要求，例如术语表、引用格式 |

规则:
- 这些文件里的要求**优先于** skill 自带的默认做法(`references/` 下的方法说明);与事实冲突时以数据为准，Claude 会说明。
- 文件不存在就用默认做法。空文件或只有注释(`<!-- -->`)的文件等于不存在。
- 在对话里说"以后报告都要……",Claude 会把这条要求写进对应文件，而不是只在这一次照做。
